## Deploy on Vercel

The easiest way to deploy your Next.js app is to use the [Vercel Platform](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) from the creators of Next.js.

### Deployment Steps

1. Go to [vercel.com](https://vercel.com) and sign in
2. Click "Add New Project"
3. Import the GitHub repository: `JohnC1009/hvac-calculator`
4. Vercel will auto-detect Next.js configuration
5. Click "Deploy"

Once deployed, your app will be available at `https://hvac-calculator.vercel.app` (or a custom domain if configured).

### CI/CD

Every push to the `main` branch will trigger an automatic deployment on Vercel (once connected).

Check out our [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
